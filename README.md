# Plan Personal de Mejora Continua

## Descripción
Plan de mejora continua de 4 semanas enfocado en desarrollar hábitos de ejercicio físico y lectura diaria mediante objetivos OKR y seguimiento del progreso.

## Objetivo
Mejorar mi disciplina, organización del tiempo y constancia mediante dos hábitos personales.

## Hábitos y objetivos

### 1. Ejercicio físico
- **Meta:** realizar ejercicio 5 veces por semana.
- **Duración:** 4 semanas.
- **Objetivo total:** 20 sesiones de ejercicio.

### 2. Lectura diaria
- **Meta:** leer 12 páginas al día.
- **Duración:** 28 días.
- **Objetivo total:** 336 páginas.

| Semana | Ejercicio | Lectura |

## Seguimiento
Se registrarán las actividades realizadas, las páginas leídas y los resultados semanales para medir el cumplimiento de los objetivos.
